# Absolute conditional initiative
Actors have integer ready ticks and stable ID tie breaking. The minimum ready living actor acts; recovery depends on action and role, with Slow adding 40 ticks. Preview clones the same scheduling transition, including status expiration, but future turns assume basic attacks; it is explicitly provisional. Forced replacement is free and required before any subsequent action.

## Fidelity correction · 2026-10-14
A voluntary living-reserve swap transfers the current action opportunity with no 35-tick cost. The incoming keeper is the current actor even when another actor shares its readiness. Chained swaps keep the same opportunity; a normal command consumes it once and applies the incoming keeper's own recovery. Swaps increment revision to invalidate stale confirmations but do not increment combat turns, gain Charge or expire status actions.

The [official FFX HD manual](https://cdn.sqexeu.com/sea/ffxii/manuals/FFX-FFX2_PS3_ManInt_English_013014.pdf), printed pages 9–11, supports immediate switched-in action. The following anti-cycling convention is a project decision, not a claim about FFX's exact formulas: retain recovery earned by previous commands on each actor, and after an immediate command recover from the later of that debt and the transferred opportunity time. Opening initiative does not count as earned recovery, so untouched Orin switched in at tick 0 recovers from tick 0. Forced fallen-slot replacements retain the existing readiness transfer/reset. No battle state is persisted, so Journey v1 saves need no migration.
