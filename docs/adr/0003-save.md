# Save the checkpoint, never an unresolved battle
Version 1 saves only canonical journey progress, coins, sparks, inventory and purchased node IDs. Starting a fight saves its pre-battle checkpoint; victory atomically increments the chapter and rewards. Reload or defeat starts the encounter again with restored resources. This sacrifices mid-fight persistence to prevent half-applied actions and duplicated rewards. Validation checks exact types, bounds, unique connected nodes and currency consistency where derivable. Storage errors surface without stopping play.
